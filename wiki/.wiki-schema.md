# LLMWiki schema (DrawSplay)

## Directory layout

- `wiki/index.md` - top-level navigation
- `wiki/purpose.md` - scope and intent
- `wiki/.wiki-schema.md` - this file
- `wiki/entities/` - concrete system components
- `wiki/topics/` - behavior and conceptual docs
- `wiki/sources/` - normalized summaries of source docs
- `wiki/synthesis/` - combined runbooks and decision guidance

## Required frontmatter

Every entry must include:

- `title` (string)
- `type` (string)
- `tags` (array)
- `created` (YYYY-MM-DD)
- `updated` (YYYY-MM-DD)
- `sources` (array)
- `summary` (string)

## Naming rules

- File names: lowercase kebab-case.
- One concept per page.
- Prefer links over duplication.
