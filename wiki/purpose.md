# Purpose

This wiki is the LLM-oriented knowledge base for DrawSplay. It extracts stable operational and architectural knowledge from source docs and keeps it split into concise, linkable entries.

Use this wiki for:

1. Fast onboarding to host/client architecture.
2. Protocol and transport behavior lookup.
3. Build, release, and operations reference.
4. Security model and trust-boundary review context.

Use source docs for authoritative detail and exact command syntax when needed.
